# MS Bonus Integration

Плагин WooCommerce для бонусной программы МойСклад. Работает поверх [WooMS](https://github.com/wpcraft-ru/wooms): берёт логин/пароль из настроек WooMS и не правит его код.

**Версия:** 1.3.0 · **PHP:** ≥ 7.4 · **WordPress:** ≥ 6.0 · **WooCommerce:** ≥ 8.0

---

## Возможности

- Баланс бонусов в личном кабинете (`/my-account/bonuses/`)
- Списание баллов на чекауте (скидка через cart fee, AJAX-пересчёт)
- Начисление баллов с оплаченного заказа при выбранном статусе
- Отложенный приветственный бонус после регистрации
- Синхронизация транзакций с МойСклад (`bonustransaction`: EARNING / SPENDING)
- Проверка соединения и просмотр параметров программы в админке
- Кэш API-запросов, обработка HTTP 429, совместимость с HPOS

## Требования

| Компонент | Нужно |
|-----------|--------|
| WooCommerce | активен |

| МойСклад | включённая бонусная программа |
| Контрагент | клиент связан с контрагентом МС (через WooMS) |

---

## Установка

1. Скопируйте папку `ms-bonus-integration` в `wp-content/plugins/`
2. Активируйте плагин в админке WordPress
3. Убедитесь, что WooMS подключён к МойСклад
4. Откройте **WooCommerce → Настройки → Бонусы МойСклад**
5. Укажите **ID бонусной программы** (UUID из МойСклад)

---

## Настройки

Путь: **WooCommerce → Настройки → Бонусы МойСклад**

| Параметр | Описание |
|----------|----------|
| **ID бонусной программы** | UUID программы в МойСклад (обязательно) |
| **Статус заказа для начисления** | `processing` или `completed` |
| **Проверка соединения** | Тест API и чтение программы |

Учётные данные не хранятся в плагине — используются опции WooMS: `woomss_login`, `woomss_pass`.

Параметры начисления, списания и приветственного бонуса задаются константами в `includes/class-ms-bonus-helpers.php` (`EARN_RATE`, `SPEND_MAX_PERCENT`, `WELCOME_BONUS_POINTS`, `WELCOME_DELAY_DAYS`).

## Как это работает

```
Клиент регистрируется
        │
        ▼
  Welcome cron (отложенно) ──► EARNING в МойСклад
        │
Клиент оформляет заказ
        │
        ├─► Checkout: выбирает списание ──► fee в корзине
        │         │
        │         ▼
        │   WooMS создаёт customerorder
        │         │
        │         ▼
        │   filter wooms_order_update ──► SPENDING в МойСклад
        │
        ▼
Статус → processing/completed ──► EARNING в МойСклад
        (если ещё нет wooms_id — повтор через WP-Cron)
```

### Списание

1. На чекауте показывается блок (только для авторизованных с контрагентом)
2. Баллы сохраняются в сессии и применяются как отрицательный fee
3. После создания заказа в МС (`wooms_order_update`) создаётся `bonustransaction` типа SPENDING

### Начисление

1. При смене статуса заказа на выбранный в настройках
2. Если нет `wooms_id` или контрагента — отложенный retry через cron
3. Повторные попытки после неудачного API-вызова не делаются (фиксируется meta)

### Приветственный бонус

При `user_register` планируется single-event cron. Если контрагент ещё не привязан — повторная попытка позже.

## Meta заказа (основные)

| Meta | Назначение |
|------|------------|
| `_ms_bonus_requested` | Запрошено к списанию на чекауте |
| `_ms_bonus_spent` | Фактически списано в МС |
| `_ms_bonus_earned` | Начислено за заказ |
| `_ms_bonus_processed` | Списание обработано |
| `_ms_bonus_error` | Текст последней ошибки |

Контрагент: meta заказа `agent_uuid` (пишет WooMS / bridge плагина).

---

## API и производительность

- Base URL: `https://api.moysklad.ru/api/remap/1.2`
- Кэш: transient между запросами + static-кэш внутри одного HTTP-запроса
- При HTTP 429 — одна повторная попытка, затем `WP_Error`
- На чекауте короткий timeout и тихая деградация (заказ не блокируется)

---

## Совместимость

- High-Performance Order Storage (HPOS) — объявлена через `FeaturesUtil`
- Работа с заказами через `WC_Order` / `$order->get_meta()`
- PHP 7.4+

---

## Отладка

- Ошибки: `MS_Bonus_Helpers::log_error` → PHP / WordPress `debug.log`
- В карточке заказа — статус начисления
- В настройках — проверка соединения с МойСклад

---

## Перед публикацией репозитория

- В коде нет логинов/паролей — только чтение опций WooMS на сайте
- UUID программы по умолчанию пустой — задаётся в админке
- Не коммитьте `.env`, дампы БД, экспорт МойСклад и папку `.tools/` (локальный PHP), если она не нужна читателям
